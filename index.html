04 / GOOD TO KNOW

The details
that matter.

Which file formats can I import?

UltraMaxMode supports TXT, Markdown, CSV, TSV, JSON, XML, HTML, text-based PDF, DOCX, XLSX and PPTX. Scanned documents and images require OCR, which is not currently available.

Can multiple people use NumShift at once?

Yes. Each browser tab has its own independent workspace; edits are not shared with other users. Refreshing the page clears the current editor session.

Does NumShift upload my content?

Editing and file extraction happen in your browser. AI title generation sends the title to OpenAI when requested; saving an export to the session workspace sends that file to the workspace.

What should I know about PDF exports?

PDFs are image-based to help preserve emoji and multilingual text, so their text is not selectable. In an embedded preview, downloads may be blocked; opening the app in a regular browser tab can help.

Is number detection always exact?

Detection uses format-based rules and grouping heuristics. Ambiguous or unusual formats may need review before replacement.
